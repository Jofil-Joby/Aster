# Aster

Aster is a local-first Chrome New Tab dashboard. It only uses Chrome's `storage` and `alarms` permissions; it has no accounts, API keys, analytics, or network dependency.

## Install

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this `aster` folder.
4. Open a new tab.

## Included

Search routing, editable shortcuts with drag reordering, daily tasks, autosaving note, local Today schedule, an alarm-backed focus timer, themes, accents, backup/import, and a reset confirmation.
