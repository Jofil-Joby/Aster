# Security Policy

## Supported version

Aster is currently maintained as a single active release line.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report the issue privately to the repository maintainer with:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested mitigation, if available

## Scope

Aster is a local Chrome extension and stores its core data through Chrome Storage. Search queries are sent to the search provider selected by the user.

Security reports are especially useful for issues involving:

- Extension permissions
- Data import or export
- Search handling
- Storage access
- Content Security Policy
- Unintended data exposure
